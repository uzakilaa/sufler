# Суфлёр

Сайт-помощник для операторов чат-поддержки банка: **Корректор** (черновик → грамотный ответ) и **Шаблоны** (поиск и копирование готовых ответов). HTML + CSS + чистый JavaScript без сборки, база — Supabase (бесплатный тариф), хостинг — GitHub Pages.

Пока в `js/config.js` не указан Supabase, сайт работает в **демо-режиме**: всё хранится в браузере, а шаблоны — выдуманные примеры. Это удобно, чтобы посмотреть сайт до подключения базы. Коды демо-режима лежат в `js/mock-backend.js` и перестают работать, как только подключена база: настоящие коды задаются в Supabase.

## Запуск: один раз, минут 15

### 1. База Supabase

1. Зарегистрироваться на [supabase.com](https://supabase.com) и создать проект (Free). Пароль базы сохранить, он нужен редко.
2. Открыть **SQL Editor → New query**, вставить целиком `supabase/schema.sql`, нажать **Run**.
3. Новый запрос: вставить `supabase/seed.sql`, **Run**. Это стартовые сокращения («прив», «спс» и др.) и словарь опечаток.
4. Новый запрос: создать коды. **Коды пишутся только здесь, в SQL Editor, в файлы сайта их класть нельзя** (репозиторий GitHub Pages публичный):

   ```sql
   select public.add_access_code('КОД_АДМИНА',    'admin', 1, 'Админ');
   select public.add_access_code('КОД_ВЛАДЕЛЬЦА', 'owner', 2, 'Владелец');
   ```

   Третий параметр — сколько человек могут быть внутри по этому коду одновременно, четвёртый — подпись в панели сессий. В базе хранится только хеш кода.

5. **Project Settings → API**: скопировать **Project URL** и публичный ключ (**anon public** или **publishable**). Вписать их в `js/config.js`:

   ```js
   window.SUFLER_CONFIG = {
     supabaseUrl: 'https://xxxxxxxx.supabase.co',
     supabaseKey: 'eyJ...',
   };
   ```

   Этот ключ публичный, его можно держать в коде: напрямую он даёт только читать шаблоны и сокращения. Секретный ключ (`service_role` / `secret`) на сайт **не класть никогда**.

### 2. GitHub Pages

1. Создать на GitHub публичный репозиторий `sufler`.
2. Загрузить в него все файлы из этой папки (кнопка **Add file → Upload files**, перетащить содержимое папки целиком, сохраняя структуру `css/`, `js/`, `supabase/`).
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`. Сохранить.
4. Через минуту сайт откроется по адресу `https://ИМЯ.github.io/sufler`.

### 3. Загрузить шаблоны из Telegram

Войти кодом владельца → вкладка **Сессии** → **Импорт шаблонов**. Вставить текст или выбрать файл (`.txt` или `.json`). Формат блоков, разделитель — строка `===`:

```
ключ: возз, возврат
название: Возврат средств
тема: Кредиты
ссылка: https://…
текст:
Полный текст ответа клиенту,
можно в несколько строк.
текст каз:
Қазақша мәтін.
===
ключ: кешб
название: Кешбэк не начислен
текст:
…
```

Тема, ссылка и казахский текст необязательны. Также принимается JSON-массив `[{"keyword": "…", "title": "…", "category": "…", "body": "…", "body_kz": "…", "link": "…"}]`. Перед импортом сайт покажет, сколько шаблонов готово и какие блоки пропущены. Галочка «заменить все текущие» сначала удаляет старые шаблоны.

## Шаблоны

- **Темы.** Наверху кнопки тем: «Все» показывает все шаблоны, сгруппированные по темам, кнопка темы оставляет только её. Поиск всегда идёт по всем темам. Админ и владелец добавляют тему кнопкой **«+ Тема»** в конце списка (или просто вписывают новую тему в форме шаблона). Пустую тему там же можно удалить.
- **Ключевые слова** пишутся через запятую: `есим, iccid, основной номер`. Поиск находит шаблон по любому из них, по названию и по тексту (с начала слова: «пт» не найдёт «оптом»).
- **Русский и казахский.** Переключатель **РУС / ҚАЗ** рядом с поиском решает, на каком языке копировать. Если казахского текста у шаблона нет, скопируется русский (сайт предупредит). В «Деталях» есть обе кнопки.
- **Подстановка из поиска.** В тексте шаблона можно оставить место: `{телефон}`, `{сумма}`, `{карта}`, `{ICCID}`, `{дата}`, `{модель}`, `{банк}`, `{MCC}`, `{мерчант}`, `{ЧСИ}`, `{обращение}`, `{имя}` (имя оператора). Оператор дописывает значение прямо в поиск, и оно встаёт в текст:

| В поиске | Что встанет |
|---|---|
| `идентиф +7 706 000 0000` (или `87060000000`) | телефон `+7 706 000 0000` |
| `iccd 8931…` | ICCID |
| `вал поступил 5000` | сумма `5 000` |
| `инактив 1234`, `инактив ***1234` | последние цифры карты |
| `пт бцк`, `пт халык`, `пт АО "ForteBank"` | официальное название банка |
| `билим привязка 1.2.2026` | дата `01.02.2026` |
| `не поддерж MTP00ZA/A`, `модель A1234` | модель |
| `мсс 1234` | MCC-код |
| `мерч 100200` | ID мерчанта |
| `заявл 123456` | номер обращения |
| `чси иванов иван иванович` (можно капсом из Колвира) | ФИО ЧСИ: «Иванов Иван Иванович» |

  Кусок в двойных скобках пропадает, если значение не дописали: `нет доступа к номеру[[ {телефон}]], мы…` → «нет доступа к номеру, мы…». Список банков и их официальных названий — в начале `js/fill.js`, его можно дополнять.

- **Предупреждение и скриншот.** В форме шаблона есть поле «Предупреждение при копировании» и место для скриншота (вставить Ctrl+V, перетащить или выбрать файл; сайт сам уменьшит картинку). Если у шаблона есть предупреждение или скрин, после копирования на весь экран выходит окно: для скрина — «сначала вставьте текст в Ч2Д, потом вернитесь за скрином», кнопки «Скопировать скрин» и «Посмотреть скрин». На карточке такие шаблоны помечены значками «скрин» и «!». Скрин хранится в базе и грузится только когда нужен.
- **«Лоханулся».** Красная кнопка рядом с поиском и в «Быстрых фразах» копирует «Просим не обращать внимания на предыдущее сообщение…». Текст берётся из шаблона «Лоханулся: предыдущее сообщение отправлено ошибочно» — его можно править.

## Избранное

У каждого кода (пароля) — свои группы избранных шаблонов: «Общий», «Динара», «Владелец» и т. д. видят каждый только свои. Звёздочка ☆ на карточке шаблона (или «В избранное» в деталях) — выбрать группу или создать новую. Группы появляются строкой над темами; «Группы…» — переименовать или удалить. Группы общие для всех, кто входит по одному и тому же коду. У гостя избранного нет.

## Программы

Вкладка **«Программы»** — рабочие системы поддержки (Ч2Д, Freedom Front, база знаний и т. д.): название и ссылка, клик открывает в новой вкладке, «Ссылка» копирует адрес. Видят все, добавляют, меняют и удаляют админ и владелец. Порядок задаёт поле «Порядок в списке».

После правки файлов сайта увеличьте число `?v=16` в ссылках на css/js в `index.html` (например, на `?v=17`): так браузеры операторов сразу возьмут новую версию, а не старую из кеша.

## Объявления о массовых сбоях

Админ и владелец видят в шапке кнопку **«Сообщить всем»**: пишут текст («Массовый сбой: переводы на Kaspi не проходят…») и выбирают, сколько его показывать — от 1 до 48 часов. Объявление появляется сверху у всех, кто открыл Суфлёр, и само исчезает, когда время выйдет; админ может снять его раньше кнопкой «Снять». Любой может скрыть объявление у себя крестиком, а вернуть — кнопкой «Объявление» в шапке. Новые объявления подтягиваются раз в минуту.

## Предложения шаблонов

Операторы (гости) предлагают новый шаблон кнопкой **«Предложить шаблон»** во вкладке «Шаблоны» или правку — кнопкой **«Предложить правку»** в «Деталях» шаблона. Имя указывать необязательно. Админы и владелец видят вкладку **«Предложения»** (с числом новых): «Открыть и добавить» открывает форму шаблона, уже заполненную предложением — можно поправить и сохранить; «Отклонить» убирает предложение в «Решённые». В «Решённых» видно, кто и когда решил. С одного адреса — не больше 20 предложений в час.

## Журнал изменений (владелец)

Во вкладке «Сессии» у владельца есть **журнал**: кто добавил, изменил или удалил шаблон, кто менял словарь, кто публиковал и снимал объявления, кто что предлагал и какие предложения приняли или отклонили. Админы и владелец видны по названию кода и имени, которое вписали при входе («Админ 2 · Айдана»; имя необязательно), операторы — по имени, которое указали в предложении. Сам код в журнал не попадает: в базе он хранится только в зашифрованном виде. Есть поиск по журналу. Журнал пишет сама база, подделать его с сайта нельзя.

## Питомцы

Внизу экрана могут гулять котик, лисёнок, ёжик, пёсик, панда, цыплёнок, зайчик, утёнок и пингвин (на телефоне четверо). По умолчанию выключены — включаются кнопкой **«Питомцы»** в подвале, браузер это запоминает. Клик — зверёк подпрыгивает и показывает пузырь с сердечком, после копирования ответа кто-нибудь радуется, если долго ничего не делать — засыпают. Код — `js/pets.js`.

Талисман в логотипе моргает пару раз, когда на него наводят мышку.

## Как устроен вход

- Гость — без кода. Админ и владелец — по коду; роль сайт определяет сам по коду.
- Код проверяется на сервере (функция `login`), в коде сайта его нет. 5 неверных попыток подряд с одного компьютера → минута блокировки. Дополнительно: 30 ошибок за 10 минут из одной сети → блокировка сети на 10 минут (страховка от подбора).
- Лимит одновременных входов на код: при занятом лимите — «Этот код сейчас используется».
- Сессия живёт 9 часов и переживает перезагрузку и закрытие браузера. Место кода освобождается: «Сменить роль» / «Выйти», через 9 часов, или когда владелец нажал «Выкинуть». Выкинутый человек становится гостем при следующем действии или возврате на вкладку.
- Шаблоны и сокращения напрямую можно только читать. Любое изменение идёт через серверные функции, которые проверяют токен сессии, роль и срок.

## Полезное в SQL Editor

```sql
-- Сменить лимит входов (сейчас: владелец — 3 человека, каждый код админа — 2)
update public.access_codes set max_sessions = 3 where role = 'owner';
update public.access_codes set max_sessions = 2 where role = 'admin';

-- Удалить код (все его сессии закончатся)
delete from public.access_codes where label = 'Админ';

-- Сменить код: удалить старый и добавить новый через add_access_code
```

Управление кодами прямо из панели владельца — второй этап по ТЗ.

## Корректор

Что исправляет: заглавные в начале предложений, точку в конце, лишние и недостающие пробелы, запятые перед «что, чтобы, потому что, так как, но, а, однако, который, если, когда, где», вводные слова («пожалуйста», «к сожалению», «например», «конечно» и др.), букву ё в частых словах, опечатки и слитные написания по словарю, сокращения. Ссылки, почта, числа и время не трогает. Изменённые слова подсвечиваются в правом поле.

Ещё он чинит текст, набранный в спешке: дописывает оборванные слова, исправляет опечатки и подбирает форму по соседним словам.

| Пишешь | Получаешь |
|---|---|
| прив да я поним что ситуац действитви неуд сорри за это мы пстраемся помоч | Здравствуйте! Да, я понимаю, что ситуация действительно неудобная. Извините за это, мы постараемся помочь. |
| ваша карта заблок изза подозрит операц | Ваша карта заблокирована из-за подозрительной операции. |
| спасиб что обратились хорошго дня | Спасибо, что обратились. Хорошего дня. |

Как это устроено: у корректора два словаря. Ручной (`js/vocab.js`) содержит слова операторов со всеми формами, по нему подбираются окончания: «мы …» → «постараемся», «в ситуац» → «в ситуации». Большой (`js/words.js`, ~47 тыс. слов) нужен, чтобы узнавать правильные слова и не трогать их. Незнакомое слово, похожее на нормальное («настройках», «реквизитов»), корректор тоже оставляет как есть.

Если корректор всё же «исправляет» правильное слово (редкий термин, название), добавьте его в **Словарь опечаток** парой «слово → слово», и он перестанет его трогать. Чтобы научить корректор новому слову операторов, допишите строку в `js/vocab.js` (формат описан в начале файла).

Ограничение честное: это правила, а не нейросеть. Причастные обороты и сложные предложения он пропустит, а запятая перед «а» или «когда» иногда может встать лишняя.

Под готовым текстом сразу появляются **варианты другим тоном**: вежливо, для жалоб (с сочувствием и извинением), коротко, как человек, официально и «после ожидания». Клик по варианту копирует его. Это тоже правила: добавляются или убираются вежливые фразы, канцелярит меняется на живые слова и обратно, смысл текста не переписывается.

**Похоже, подойдёт шаблон.** Если в черновике есть ключевое слово шаблона (например, «в работе сорри»), под ответом появятся до трёх подходящих шаблонов — клик копирует.

**Быстрые фразы.** Внизу вкладки — живая схема частых фраз по ходу диалога: приветствие → уточню → ожидайте → передали специалистам → в работе, плюс ответвления «изучу переписку», «продолжаем», «на контроле». Клик копирует, наведение показывает текст. «Кешбэк · 48 часов» выделена золотым — её копируют чаще всего. Тексты берутся из шаблонов темы «Быстрые фразы» (по названию), их можно править как обычные шаблоны. Поле «Меня зовут» запоминает имя оператора в этом браузере, оно встаёт вместо `{имя}` в любом шаблоне.

Сокращения и словарь ведут админ и владелец: кнопка **Сокращения и словарь** под черновиком. Гость видит список как шпаргалку.

## Риски

Бесплатный проект Supabase засыпает после 7 дней без запросов. После долгих праздников зайти в панель Supabase и нажать **Restore project**. Пока база спит, сайт показывает последние сохранённые в браузере шаблоны, а корректор работает как обычно.
