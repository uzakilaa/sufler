# Суфлёр

Помощник оператора чата поддержки: поиск шаблонов ответов, умный корректор с переводом на казахский и английский, рабочие ссылки.

Рабочая версия живёт на claude.ai как Artifact: https://claude.ai/artifact/Fo4vgVWdVuStc77foUHNMY

## Что здесь

- `sufler.html` — код страницы (HTML, CSS, JS в одном файле).

Шаблоны, ссылки и личные настройки в репозитории не хранятся: они лежат в базе артефакта на claude.ai. Корректор, база и права доступа работают только внутри claude.ai (через `window.claude`), поэтому файл, открытый отдельно, покажет пустой сайт.

## Разделы

- **Шаблоны** (Alt+Q) — поиск по словам и тегам, блоки, избранное, статусы «На проверку» / «Неактуально по БЗ».
- **Добавить** (Alt+W) — новый шаблон или правка, ИИ подбирает теги и переводит на KZ. Только для редакторов.
- **Корректор** (Alt+E) — черновик → готовый вежливый ответ и 3–7 вариантов (Alt+1…7), RU / KZ / EN.
- **Ссылки** (Alt+R) — рабочие программы и ссылки для клиентов. Только для редакторов.

## Доступы

Задаются в меню «Поделиться» артефакта: Редактор правит шаблоны, Просмотр/Участник только ищут, копируют и пользуются корректором.
