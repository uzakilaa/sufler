# Суфлёр

Помощник оператора чата поддержки: поиск шаблонов ответов, корректор черновиков с вариантами ответа, быстрые ответы и рабочие ссылки.

## Два режима, один код

| | На claude.ai | Как обычный сайт (GitHub Pages, любой хостинг, локальный файл) |
|---|---|---|
| Где шаблоны | общая база артефакта | в этом браузере (IndexedDB), загружаются из файла базы |
| Корректор | ИИ (Claude): исправление + 5–7 вариантов, RU/KZ/EN | без ИИ: сокращения, «ты» → «Вы», орфография через LanguageTool, 5 вариантов по правилам |
| Мгновенные ответы на «изуч», «жди», «тикет в работе»… | да | да |
| Пароли редакторов, общие права | да | нет (каждый работает со своей копией базы) |

Рабочая версия на claude.ai: https://claude.ai/artifact/Fo4vgVWdVuStc77foUHNMY

## Файлы

- `sufler.html` — исходник (так он публикуется на claude.ai).
- `index.html` — та же страница, обёрнутая в полноценный HTML-документ для GitHub Pages. Собирается командой `sh build.sh`.
- `.gitignore` — запрещает коммитить `*.json`: файлы базы содержат внутреннюю информацию и в репозиторий не кладутся.

## Как пользоваться сайтом без claude.ai

1. Открыть `index.html` (GitHub Pages или просто двойным кликом).
2. При первом запуске выбрать «Загрузить файл базы» (`sufler-base.json`) или «Начать с примеров».
3. Перенести базу на другой компьютер: «Добавить» → «Скачать базу (.json)», там «Загрузить файл базы».

Проверка орфографии использует бесплатный публичный API LanguageTool (api.languagetool.org): текст черновика отправляется туда. Без интернета исправляются только сокращения и обращение на «Вы».

## Горячие клавиши

Alt+Q шаблоны · Alt+W добавить · Alt+E корректор · Alt+R ссылки · Alt+1…9 скопировать вариант / быстрый ответ · Ctrl+Enter скопировать готовый ответ.
