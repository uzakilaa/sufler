# Суфлёр

Помощник оператора чата поддержки: поиск шаблонов, корректор черновиков с 5 вариантами ответа, быстрые ответы, рабочие ссылки.

## Как это работает

- **Сайт** — `index.html` на GitHub Pages. Открывается по ссылке, аккаунты не нужны.
- **Сервер** — `server/Code.gs`, Google Apps Script. База шаблонов и ссылок лежит в Google Таблице владельца, пароли проверяются на сервере.
- **Гость** — поиск, копирование, корректор.
- **Редактор** — вводит пароль. Один пароль закрепляется за одним устройством (браузером), второй человек с ним не войдёт.
- **Админ** — видит, кто занял пароли, освобождает их, загружает и скачивает базу (раздел «Добавить» → «База шаблонов»).

## Установка сервера (один раз, ~10 минут)

1. Создайте Google Таблицу (sheets.new), назовите «Суфлёр база».
2. В таблице: «Расширения» → «Apps Script». Удалите всё в редакторе и вставьте содержимое `server/Code.gs`.
3. Впишите в начале файла свои пароли: `ADMIN_PASSWORD` и `EDITOR_PASSWORDS`. **Только в редакторе Apps Script, не в GitHub.**
4. Сохраните (Ctrl+S). Сверху выберите функцию `setup` → «Выполнить» → разрешите доступ к таблице.
5. «Развернуть» → «Новое развертывание» → значок шестерёнки → «Веб-приложение».
   «Выполнять как»: **Я**. «У кого есть доступ»: **Все**. Нажмите «Развернуть» и скопируйте URL веб-приложения.
6. Впишите этот URL в `config.js`: `window.SUFLER_API = "https://script.google.com/macros/s/…/exec";`

Поменять пароли позже: исправьте их в Apps Script и запустите функцию `resetPasswords` (все пароли освободятся).

## Файлы

- `sufler.html` — исходник страницы (этот же код работает и как артефакт на claude.ai).
- `index.html` — собранная страница для Pages: `sh build.sh`.
- `config.js` — адрес сервера. Пусто → база хранится только в браузере.
- `server/Code.gs` — сервер.
- Файлы базы (`*.json`) в репозиторий не кладутся (`.gitignore`): в них внутренняя информация.

## Корректор

Без ИИ: сокращения («здравст», «спс», «щас»…), «ты» → «Вы», заглавные и точки, орфография через публичный API LanguageTool (текст черновика отправляется на api.languagetool.org), 5 вариантов: вежливо, с эмпатией, коротко, простыми словами, по-человечески. Типовые фразы («изуч», «жди», «тикет в работе», «наплыв») дают готовый ответ сразу.

## Горячие клавиши

Alt+Q шаблоны · Alt+W добавить · Alt+E корректор · Alt+R ссылки · Alt+1…9 вариант / быстрый ответ · Ctrl+Enter скопировать готовый ответ.
